# 自来水厂水质预测与评估：数据预处理与探索性分析

本目录中的代码对应题目四问在建模前的数据处理和探索性分析部分。

## 文件说明

- `src/data_preprocessing.py`：统一读取附件 1 的月度 `.xlsx` 和附件 2 的逐日工作表 `.xls`，修复日期、清洗缺失值、标记异常值与反冲洗事件，并生成质量报告。
- `src/prob1.py`：出厂水浊度影响因素、周期性、季节性及多模型预测。
- `src/question2_eda.py`：滤后水浊度及不同输入变量时滞的初步识别。
- `src/question3_eda.py`：出厂水浊度多步预测前的动态特征探索。
- `src/question4_eda.py`：2026 年 1—3 月超标幅度、持续时间和阈值敏感性探索。
- `src/eda_common.py`：四问共用的绘图和数据读取函数。

## 运行顺序

```powershell
python -m pip install -r requirements.txt
python src/data_preprocessing.py
python src/prob1.py
python src/question2_eda.py
python src/question3_eda.py
python src/question4_eda.py
```

结果统一写入 `outputs`。图片同时保存为 300 dpi PNG 和 SVG，图内中文字体设置为黑体，按要求不设置图标题。

## 数据处理口径

1. 2025 年部分工作簿的前 12 天发生日、月颠倒，代码以文件名月份为准重建日期。
2. 每个运行日从 07:00 记录至次日 05:00，因此 01:00、03:00、05:00 归入下一自然日，同时保留所属运行日字段。
3. 2025 年 5—8 月缺少若干整列指标，这些属于结构性缺失，不进行跨月插补。
4. 仅对同一源文件内、连续不超过 3 个采样点的非目标数值变量进行时间插值。滤后水浊度和出厂水浊度不插补。
5. 异常点只做标记，不自动删除。备注中的 `B/W`、`backwash`、`filter` 等信息会生成反冲洗事件标记，便于解释浊度突变。
6. 题目称每天 12 次采样；代码会根据时间戳实际检查 2 小时间隔和缺口，不直接假定数据绝对完整。
7. 附件 2 的 2026 年 2 月出厂水 `NTU` 整列为空。探索性分析将其明确保留为待预测区间，风险统计不会把缺测值当成 0 或“安全”。
